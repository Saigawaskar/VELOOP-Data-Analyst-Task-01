## Data integrity statement

The supplied VELOOP assignment data is fictional/simulated for analytical testing. This repository does not present simulated rows or calculated metrics as actual VELOOP production performance, revenue, retention, withdrawals or company statistics.

Any additional operational-style datasets are clearly labelled as **SIMULATED DATA — CREATED FOR ANALYTICAL TESTING**.

## Run locally

No backend is required.

1. Open `index.html` directly in a modern browser, or
2. Serve the repository with any static web server.

## Deploy to Vercel

The repository is configured as a static site with `index.html` at the repository root. Import the GitHub repository in Vercel and deploy with the default static settings.
