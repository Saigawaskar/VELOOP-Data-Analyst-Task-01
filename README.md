# VELOOP Rewards — Data Analyst Internship Task 01

**Made by Sai Sunil Gawaskar**

Responsive static analytics dashboard / implementation for the VELOOP Task 01 submission.

## What this includes
- Responsive analytics overview and navigation
- User, engagement, rewards, wallet, withdrawals and referral views
- Data quality audit view
- Implementation backlog and readiness scorecard
- Links to the final report, master workbook and engineering diagrams
- Clear simulated-data disclosure

## Run locally
Open `index.html` in a browser, or serve the folder with a simple static server.

## Deploy
This is a static site and can be deployed to Vercel or Netlify. No server-side secrets are required.

## Integrity note
Supplied user data and created operational datasets are treated as simulated analytical testing data. The dashboard must not be presented as actual VELOOP production performance.
